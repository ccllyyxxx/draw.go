# Draw.go

Draw.go is a spec-driven application for graphics and drawing.

## Project Structure
- `specs/`: Spec-Driven Development documentation, requirements, architecture, and feature specifications.
  - `specs/constitution.md`: Core project principles and rules.
  - `specs/architecture/`: Architectural Decision Records (ADRs) and system designs.
  - `specs/features/`: Functional & feature specifications.
  - `specs/tasks/`: Implementation tasks and checklists.
  - `specs/api/`: API specifications and schemas.
